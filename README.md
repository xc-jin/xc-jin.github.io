# Xuancheng Jin's research homepage

A standalone academic website at <https://xc-jin.github.io/>.

The site uses plain HTML, CSS, and JavaScript. No package installation or build step is required.

## Local preview

Run `python -m http.server 8000` in this directory and open <http://localhost:8000>.

## Editing

- `index.html`: biography, research interests, publications, and links.
- `assets/style.css`: responsive layout and light/dark themes.
- `assets/site.js`: theme selection and footer year.
- `assets/favicon.svg`: browser icon.

## Publishing

Push to the `main` branch of `xc-jin/xc-jin.github.io`. GitHub Pages serves the repository root.
